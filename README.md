# 📱 Flutter Ürün Kataloğu Uygulaması

Bu proje, temel Flutter widget'larını ve sayfa yönetimini öğrenmek amacıyla geliştirilmiş kapsamlı bir katalog mobil uygulamasıdır.

## ✨ Özellikler
- **Giriş Sistemi:** Kullanıcı adı kontrolü ve LocalStorage ile isim saklama.
- **Dinamik Katalog:** Ürün listeleme ve anlık arama (filtreleme).
- **Sepet Sistemi:** Sepete ürün ekleme, çıkarma ve toplam fiyat hesaplama.
- **Görsel Bildirimler:** Sepet ikonu üzerinde dinamik ürün sayısı (Badge).
